صفحة تسجيل دخول بسيطة

مشروع تصميم صفحة تسجيل دخول عربية باستخدام HTML و CSS.
واجهة بسيطة تم تنسيقها بشكل أنيق لعرض نموذج تسجيل دخول مع لمسة تصميمية مميزة.

⸻

فكرة المشروع:

إنشاء صفحة تسجيل دخول (Login Page) تحتوي على:
 • حقل اسم المستخدم.
 • حقل كلمة المرور.
 • زر إرسال.
 • خلفية أنيقة بصورة كيك لإضفاء طابع جذاب وودود على التصميم.

⸻

التقنيات المستخدمة:
 • HTML5
 • CSS3
